### Hello there! 👋

- ⚡ November 25, 2026 [ZanBar](https://github.com/Zanphar/ZanBar) 1.1.0 Designed for Windows 10/11, a menu bar that brings the macOS menu-bar pattern to the top of the desktop. It is a single portable executable that can be used without installing, or installed using an installer.
- ⚡ November 21, 2026 [GameTCP 4](https://github.com/Zanphar/GameTCP) (4th generation) has been published. This is a complete GUI now, with the option for CLI switches. It has been ported from Visual Basic .NET to C++ (MSVC or MingW for those who prefer).
- ⚡ November 15 2026, [Internet Checker](https://github.com/Zanphar/Internet-Checker-Suite), which contains several things to assist in resetting and helping with configuring network connections on the system. I was having some issues with Battlefield 6 tonight and a few things I did (and didn't) do, this has done. **coming soon**
- ⚡ November 16, 2026, [Zanphar's WinSuite](https://github.com/Zanphar/Zanphar-s-WinSuite), inspired by other popular tools on the internet that have been released to the public, because, why not? Sorry about the mess, will work on cleaning that up at a later date.

- More content and information is coming in the future, please keep an eye out--something is bound to be interesting. :-)

There's a few things that are in planning stages, some are in progress and soon should be released to the public. Additionally, while it's a 2019 MacBook Pro, some content for macOS should also be released along with Linux software. :-)
